- D. 요청하신 단호하지만 정중한 독촉장이에요. "볼로냐 시청(Comune di Bologna) 주민등록과 귀중: 저는 법정 기간 안에 거주지 변경을 신고했으나 확인을 받지 못했습니다. 등록된 날짜를 서면으로 알려 주시기 바랍니다." 등기우편으로 보내거나 창구에 직접 제출하시면 됩니다.
