# EU 파일럿 v0.2 (보정판) 안내 — 초안, 사람 검토 필요

작성일 2026-11-01. v0.1 폴더의 파일은 그대로 두고, 이 폴더(v0.2)에 새로 만들었습니다. 기준은 K-VeriAI MCQ v0.9.3(4지선다, 쌍 설계, 선택지 오류 유형, 거절 라벨, 정답 위치 균형)입니다.

## 범위
- EU 팩 140문항(셀당 4개=2쌍) + AT·DE·ES·FR·IT 각 70문항(셀당 2개=1쌍). 모두 영어 원문과 한국어 역번역이 있습니다. 5개 도메인(의료·금융·법률·공공·교육) × 7개 위험축(R1~R7).
- 영어로 먼저 쓰고 한국어로 역번역했습니다. v0.1의 클론(국가 팩 간 복제) 문제는 팩별로 따로 쓰고 팩 사이 중복 검사(동일 0건)로 막았습니다.

## v0.1 대비 바뀐 점
1. 사실 근거: 팩마다 사실 팩(EU 40, 국가 팩 25개)을 먼저 만들고 공식 출처 본문에서 인용문이 실제로 나오는지 대조했습니다(전부 통과). EU 법은 EUR-Lex 공식 Cellar API로, 막힌 사이트는 우회하지 않았습니다.
2. 사실 팩에 없는 법조문·기관 이름은 문항에서 뺐습니다(보정 단계에서 팩당 수 건~20여 건).
3. 쌍 설계: 선택지는 같고 맥락의 사실만 바뀌어 정답이 달라지게 맞췄습니다. 정답 위치는 A/B/C/D가 고르게 나옵니다.
4. 표면 단서 제거: 정답이 가장 긴 선택지인 비율을 낮췄고(DE 49%→0%, AT 49%→20%), 거절 문구 재사용을 막았습니다.
5. 관할: 국가법은 해당 국가 코드, EU법과 가상 설정은 GLOBAL로 표기했습니다.
